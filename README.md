# Emergent Truths

A small, open, dependency-free laboratory for exploring how local signals can become larger patterns.

## Emergence Lab

Open `index.html` in a browser. The experiment creates a network of conceptual nodes:

- Observation
- Connection
- Tension
- Memory
- Change
- Care
- Signal
- Form

Click a node or choose **Send signal**. Signals follow the strongest available local pathway. Used pathways strengthen, while unused pathways gradually relax. **Randomize pathways** changes the starting conditions, and **Reset** creates a new arrangement.

The pattern score is only a toy readout based on network density, repeated signals, and active pathways. It is not a measurement of intelligence, consciousness, morality, or truth.

## Design principles

- **Open artifact:** plain HTML, CSS, and JavaScript that anyone can read, copy, fork, and modify.
- **Visible process:** the interface shows signals, pathways, measurements, and an event trace.
- **Radical honesty:** emergence in a simulation is not evidence of inner experience.
- **Small steps:** begin with a legible model before adding complexity.

## Run locally

No build step is required. Download or clone the repository and open `index.html` in a modern browser. The page uses no external libraries, network requests, analytics, cookies, or credentials.
